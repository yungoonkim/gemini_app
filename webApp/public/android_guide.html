STEP 03

3단계: 테스트할 기기 준비하기 (가상폰 vs 실제 스마트폰)

앱을 띄울 기기를 선택합니다. 컴퓨터 화면에 스마트폰을 띄우는 가상폰(에뮬레이터) 방식과 내 손에 있는 진짜 스마트폰을 연결하는 방식 중 편한 것을 선택하세요.

방법 A: 가상 스마트폰 (추천 👍)

선 연결 없이 모니터 안에서 안드로이드 폰이 켜집니다.

  1. 우측 사이드바의 Device Manager 아이콘 클릭
  2. + (Create Virtual Device) 클릭
  3. Phone 목록에서 Pixel 8 선택 후 Next
  4. 시스템 이미지(VanillaIceCream/UpsideDownCake) 다운로드 후 Finish
  5. 재생(▶) 버튼을 누르면 화면에 가상 폰이 켜집니다!
방법 B: 실제 안드로이드 폰 (갤럭시 등)

진짜 내 스마트폰에 앱을 깔아서 테스트합니다.

  1. 폰 설정 → 휴대전화 정보 → 소프트웨어 정보 진입
  2. '빌드번호' 항목을 빠르게 7번 연속 터치! (개발자 모드 활성화)
  3. 설정 맨 아래에 생긴 개발자 옵션 → USB 디버깅 켜기
  4. USB 케이블로 PC와 폰 연결 → 폰 화면에 뜨는 "USB 디버깅 항상 허용" 확인
STEP 04

STEP 05

5단계: 앱에서 Gemini 3.8 Flash 핵심 기능 테스트하기

안드로이드 앱이 켜지면 아래 핵심 기능들을 직접 체험해볼 수 있습니다.

🌐 1. 실시간 구글 웹 검색 (Grounding)

"오늘 서울 송파구 문정동 날씨 어때?"라고 물어보세요. 하단에 실시간 검색어 칩과 기상청 웹사이트 출처 링크가 생성됩니다.

🖼️ 2. 멀티모달 이미지 분석

입력창 좌측 갤러리 아이콘을 누르면 안드로이드 갤러리나 카메라가 열려 사진을 첨부하고 AI에게 분석을 요청할 수 있습니다.

🎤 3. 한국어 음성 인식 (STT)

마이크 버튼을 누르면 마이크 권한 요청이 뜨고, 음성으로 말하면 글자로 자동 변환되어 질문을 작성합니다.

☁️ 4. 클라우드 자동 동기화

Google Cloud Run 프로덕션 서버와 Firebase Firestore로 대화 기록이 실시간으로 안전하게 동기화됩니다.

BONUS GUIDE

🎁 보너스: 친구나 내 폰에 설치할 수 있는 APK 파일 만들기

안드로이드 스튜디오를 켜지 않고도 카카오톡이나 구글 드라이브로 파일을 전송해 폰에 바로 설치할 수 있는 .apk 파일을 만드는 방법입니다.

  1. 상단 메뉴바에서 Build 클릭
  2. Build Bundle(s) / APK(s) 마우스 오버 → Build APK(s) 클릭
  3. 10~20초 후 우측 하단에 "APK(s) generated successfully" 알림창이 뜹니다.
  4. 알림창의 파란색 글씨인 locate를 클릭하면 탐색기가 열리며 app-debug.apk 파일이 나타납니다.
  5. 이 파일을 카카오톡 '나와의 채팅'으로 보내서 스마트폰에서 다운로드 후 설치하시면 끝납니다!
FAQ & TROUBLESHOOTING

❓ 자주 묻는 질문 & 문제 해결

Q1. "Android SDK가 설치되어 있지 않다"고 에러가 떠요!
안드로이드 스튜디오를 방금 처음 설치하셨다면 발생하는 정상적인 안내입니다. 팝업창에서 Install missing SDK 링크나 버튼을 클릭하시면 안드로이드 스튜디오가 알아서 최신 SDK 35를 1분 안에 다운로드해줍니다.
Q2. 로컬 컴퓨터(webApp 폴더)의 Node.js 서버와 연동해서 테스트하고 싶어요!
기본적으로는 Google Cloud Run 클라우드 서버에 접속되도록 설정되어 있습니다. 컴퓨터에서 webApp 폴더의 node server.js를 켜놓고 안드로이드 에뮬레이터에서 로컬 서버로 붙이고 싶다면, 안드로이드 가상폰 브라우저 주소인 http://10.0.2.2:3000을 사용하시면 됩니다 (10.0.2.2는 안드로이드 에뮬레이터가 내 컴퓨터의 localhost를 가리키는 특별한 IP입니다).
Q3. 실제 스마트폰을 컴퓨터에 꽂았는데 기기 목록에 안 떠요!
1) 스마트폰의 USB 디버깅이 켜져 있는지 확인해주세요.
2) 단순 충전 전용 케이블이 아닌 데이터 전송이 가능한 정품 USB 케이블을 사용해주세요.
3) 폰 화면을 켰을 때 "이 컴퓨터에서 항상 디버깅을 허용하시겠습니까?"라는 팝업이 뜨면 허용을 눌러주셔야 기기가 인식됩니다.
