  1. 스마트폰 기본 카메라 앱으로 상단 QR 코드를 스캔하여 Chrome 브라우저로 접속합니다.
  2. 화면 하단에 뜨는 '홈 화면에 Gemini Studio 추가' 배너를 터치합니다.
  3. 또는 Chrome 우측 상단 더보기(⋮) 메뉴에서 [앱 설치]를 선택합니다.
  4. 스마트폰 홈 화면과 앱 서랍에 설치되어 전체화면 네이티브 앱으로 동작합니다.
  1. 기본 카메라 앱으로 상단 QR 코드를 비추어 Safari 브라우저로 엽니다.

  3. 메뉴를 위로 올려 [홈 화면에 추가]를 누른 후 우측 상단 [추가]를 선택합니다.
  4. 아이폰 홈 화면에 Gemini Studio 앱 아이콘이 생성되어 주소창 없이 앱처럼 실행됩니다.
