# Gemini 3.8 Flash Studio - 웹 채팅 서비스

Google의 차세대 플래그십 모델인 **Gemini 3.8 Flash** (`gemini-3.8-flash`)를 기본 모델로 탑재한 고성능 대화형 웹 서비스입니다.

---

## 🌟 주요 기능 및 특징

1. **Gemini 3.8 Flash 기본 탑재**:
   - 2026년 9월 출시된 최신 고지능·초고속 추론 엔진 (`gemini-3.8-flash`) 적용.
   - 1,048,576(1M) 토큰 대규모 컨텍스트 윈도우 및 최대 65,536 토큰 출력 지원.
   - 복잡한 다단계 추론 및 코드 엔지니어링 작업에 최적화.

2. **실시간 SSE (Server-Sent Events) 스트리밍**:
   - 타자기 효과 및 깜빡이는 커서와 함께 실시간 토큰 스트리밍 제공.
   - 응답 생성 지연시간(Latency) 자동 측정 및 뱃지 표시.

3. **풍부한 마크다운 & 코드 렌더링**:
   - `Marked.js` 및 `Highlight.js`를 통합하여 다크 테마 기반 코드 구문 강조.
   - 코드 블록 상단에 언어 표시 및 1-클릭 클립보드 복사(Copy) 기능 제공.
   - 테이블, 인용구, 헤딩, 리스트 완벽 지원.

4. **멀티모달 이미지 분석**:
   - 클립보드 붙여넣기(Ctrl+V), 드래그 앤 드롭, 파일 첨부 버튼을 통한 이미지(PNG, JPG, WebP) 업로드 지원.
   - Gemini 3.8 Flash의 고성능 비전 엔진으로 다이어그램, 사진, 스크린샷 심층 분석.

5. **음성 지원 (Speech AI)**:
   - **TTS (Text-to-Speech)**: Gemini 응답을 한국어로 즉시 읽어주는 음성 출력 기능.
   - **STT (Speech-to-Text)**: 마이크 버튼을 통한 실시간 한국어 음성 인식 입력 기능.

6. **대화 세션 & 히스토리 관리**:
   - 브라우저 로컬 저장소(`localStorage`) 기반으로 대화 목록 자동 보관.
   - 첫 질문에 맞춰 대화 제목 자동 지정, 새 대화 생성 및 개별 대화 삭제 지원.

7. **세밀한 환경 설정**:
   - **API Key**: 시스템 환경 변수 및 루트 `.env` 파일의 `GEMINI_API_KEY`를 자동으로 안전하게 로드하여 사용합니다. (클라이언트에서 노출되거나 별도 입력할 필요가 없습니다.)
   - **온도(Temperature)**: 0.0(결정론적/정확함) ~ 2.0(창의적) 실시간 슬라이더 조정.
   - **시스템 페르소나**: 시니어 엔지니어, 테크니컬 라이터, 전문 번역가 및 커스텀 프롬프트 선택 가능.
   - **테마 전환**: 현대적인 다크 모드(기본) 및 라이트 모드 1-클릭 전환.

## 🚀 실행 방법

### 1. 의존성 설치
```bash
npm install
```

### 2. 서버 실행
```bash
npm start
# 또는 개발 모드
npm run dev
```

### 3. 브라우저 접속
웹 브라우저를 열고 다음 주소로 접속합니다:
👉 **[http://localhost:3000](http://localhost:3000)**
