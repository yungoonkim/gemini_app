  • 모달 닫기(closeAuthModal) 엄격 격리: try 블록 후미에 있던 무조건 닫기 호출을 제거하고, Firebase 실제 인증 성공(userCredential) 분기 내에서만 안전하게 닫히도록 로직 수정
  • 배경 오버레이(Backdrop) 오작동 방지: 마우스 드래그나 오류 발생 시 레이아웃 높이 변화(Reflow)로 인해 클릭이 오버레이로 유실되어 모달이 닫히던 현상을 방지하기 위해 mousedown과 click이 모두 오버레이 본체에서 발생했을 때만 닫히도록 방어 코드 구축
  • 모달 내부 이벤트 전파 차단 (stopPropagation): .modal-dialog 카드 내부 클릭 및 마우스 이벤트가 오버레이로 버블링되지 않도록 원천 차단
  • 폼 전송 버튼 타입 안정화: button[type="submit"]을 type="button"으로 전환하고 엔터키 이벤트 및 preventDefault()를 명시 처리하여 예기치 않은 네이티브 폼 제출/새로고침 차단
  • 실패 피드백 시각화 (Shake 애니메이션): 인증 실패 시 팝업 창이 좌우로 흔들리는 부드러운 modal-shake 애니메이션 적용 및 ⚠️ 이메일 또는 비밀번호가 일치하지 않습니다. 경고 배너 표시
  • 비밀번호 입력창 자동 포커스: 인증 실패 시 사용자가 비밀번호를 즉시 다시 입력할 수 있도록 비밀번호 필드에 포커스 및 텍스트 선택(select) 자동 적용
